# Renamer

## **ENGLISH**

**Renamer** is a tool for renaming multiple files at once, organizing them into a numerical sequence.

For example:

```text
picture.png
coolpicture.png
download1.png
image.png
```

can be renamed to:

```text
1.png
2.png
3.png
4.png
```

### What is it for?

Imagine you downloaded a lot of images from Pinterest and saved them in different folders. Over time, many of them may end up having the same names, such as `download.png`, `download1.png`, `download2.png`, and so on.

When you try to move all these images into a single folder, Windows may detect files with the same name and ask whether you want to replace the existing file, keep both files, or rename them manually.

Renamer solves this problem by allowing you to **rename the files before moving them**, turning their names into a numerical sequence while keeping their original file extensions.

For example:

```text
Folder 1/
├── download.png
├── download1.png
└── picture.png

Folder 2/
├── download.png
├── image.png
└── download1.png
```

can become:

```text
1.png
2.png
3.png
4.png
5.png
6.png
```

making it easier to organize your files and avoid filename conflicts.

## **PORTUGUÊS BRASILEIRO**

O **Renamer** é uma ferramenta para renomear vários arquivos de uma só vez, organizando-os em uma sequência numérica.

Por exemplo:

```text
foto.png
fotolegal.png

download1.png
imagem.png
```

pode ser transformado em:

```text
1.png
2.png
3.png
4.png
```

### Para que serve?

Imagine que você baixou várias imagens do Pinterest e guardou elas em pastas diferentes. Com o tempo, várias delas podem acabar tendo o mesmo nome, como `download.png`, `download1.png`, `download2.png` etc.

Quando você tenta juntar todas essas imagens em uma única pasta, o Windows pode detectar arquivos com o mesmo nome e pedir para substituir, manter ambos ou renomear os arquivos manualmente.

O Renamer resolve esse problema permitindo **renomear os arquivos antes de juntá-los**, transformando seus nomes em uma sequência numérica e mantendo a extensão original.

Assim:

```text
Pasta 1/
├── download.png
├── download1.png
└── foto.png

Pasta 2/
├── download.png
├── imagem.png
└── download1.png
```

pode se tornar:

```text
1.png
2.png
3.png
4.png
5.png
6.png
```

facilitando a organização e evitando conflitos de nomes.
